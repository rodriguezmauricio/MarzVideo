MODE: interactive

ONE-SENTENCE CONCEPT
Marz Recorder as a printed contact sheet and film slate: the editor is a ruled timecode ledger where time is the architecture, and the only loud thing is a number.

THE CONCEPTUAL CONFLICT
"Record once, decide later": nothing is baked in, so the UI must show everything as separate, exposed layers (screen, mic, clicks, zooms, cuts) instead of hiding them behind friendly chrome. Precision and exposure versus the calm, trustworthy feel the brief demands.

SCHOOL
Editorial Brutalism. Moves deployed: exposed column and baseline grid as graphics; extreme scale contrast (giant timecode against 11px mono captions); ink, paper, one accent.

THE FORMAL MOVES (3 to 5)
- Timecode as display type (current time at 200px+, cropped by the canvas edge) -> time is the thing you edit, so it is the biggest object on screen.
- Visible 12-column grid rules and a ruled ledger for the timeline, every lane labelled in 11px uppercase mono -> "nothing is baked in" made literal; every track is its own ruled row.
- Inverted ink/paper panels: inspector and Home hero on paper (off-white), editor canvas on ink -> separates "what you shape" from "the thing being shaped" without chrome.
- One accent (placeholder #4F8CFF) for zooms and primary action only; red only for recording and cuts -> keeps the semantic colour budget from the brief.

WHAT THIS PIECE REJECTS
- Rounded dark SaaS panels with soft borders and a tab bar of icon buttons.
- Centered hero with a big button and a card grid of thumbnails floating on a gradient-free dark void.
- Friendly onboarding tone (illustrations, emoji, reassurance copy). Replaced by flat, factual captions.

REFERENCE PIECE
ASSUMED: Folder Studio site and Wim Crouwel's grid posters, with Screen Studio's restraint as the product-quality bar. Replace if you have a better one.

TYPOGRAPHY
Brand words: dense, unimpressed, exact.
Reflex fonts rejected: Inter, JetBrains Mono, Space Grotesk.
Display and UI: ABC Monument Grotesk (Dinamo, paid). Captions, timecodes, labels: ABC Diatype Semi-Mono (Dinamo, paid). Why: "exact" and "unimpressed" want a blunt grotesk with a mono sibling, not a friendly geometric sans. Rejected alternative: JetBrains Mono for all text, because it signals "developer tool" instead of "editing room".
Free fallbacks in the file (not banned): Familjen Grotesk (display), Martian Mono (captions).
ASSET NEEDED: ABC Monument Grotesk and ABC Diatype Semi-Mono font files, if you want the paid faces.

STRUCTURAL SKETCH
- Grid: 12 columns, 1px rules at 14% opacity left visible across Home and Editor; content snaps to columns, never floats.
- Hierarchy: timecode 220px (Familjen Grotesk 700, line-height .82, letter-spacing -.04em) against 11px uppercase Martian Mono captions, nothing between except 15px labels.
- Colour: ink #0B0C0F, paper #ECEAE4, accent #4F8CFF (one value), recording red #D93A40. Inspector and Home hero are paper-on-ink inversions.
- Conflict shown: the editor timeline is a ruled ledger with every lane visible by default (Screen, Mic, Zoom, Cuts, plus the greyed "Later" rows); the Home screen leads with the recover banner as a full-width ruled row.
- Deliberately wrong: the huge timecode is cropped by the canvas edge and overlaps the preview's corner; Home project names are set at 28px mono in a table, not as cards.
